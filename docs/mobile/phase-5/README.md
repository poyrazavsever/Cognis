# Phase 5 - API contract package and resource infrastructure

Last updated: 2026-07-25

Phase 5 is implemented for the mobile/client side. Server route helper work is
still pending because this repository currently contains only the mobile
workspace.

## Implemented

- `packages/api-contracts` contains transport-safe TypeScript contracts.
- Envelope, error, pagination and localized response guards are dependency-free.
- Dashboard and analytics contracts are represented as JSON-safe data shapes.
- Mobile has an instance-bound resource request helper with timeout, request
  metadata headers and parser-based contract validation.
- Query keys follow `[instanceId, role, locale, resource, filters]`.
- Read cache is persisted with small TTL policies through AsyncStorage.
- Idempotency keys are generated by `createIdempotencyKey(prefix)`.

## Decisions

- No TanStack Query dependency yet. The app uses a tiny local helper until enough
  feature screens exist to justify a larger query/cache runtime.
- Optimistic concurrency is contract-first: update endpoints must accept a last
  known `version` or `updatedAt` once mutations arrive.
- OpenAPI generation is not implemented yet. The near-term machine-readable
  source is `packages/api-contracts`; backend can later generate OpenAPI from
  the same route schemas when the server repository is available.

## Validation

- `pnpm --filter @neta/mobile check` passes.
- Unit tests cover envelope, pagination, dashboard contract, query key stability,
  idempotency key shape and formatting helpers.
